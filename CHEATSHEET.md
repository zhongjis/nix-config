# Cheatsheet

## CLIProxyAPI and CPA Usage Keeper

Copy the CLIProxyAPI client API key:

```bash
wl-copy < ~/.local/state/cliproxyapi/api-key
```

Copy the CPA Usage Keeper admin password:

```bash
wl-copy < ~/.local/state/cpa-usage-keeper/login-password
```

These commands copy secrets to the clipboard without printing them in the terminal. Clear the clipboard after use.
