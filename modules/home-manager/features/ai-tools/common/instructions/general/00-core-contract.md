# Final-State Contract

- **Scope:** Treat the current request as the boundary. Every changed line must be necessary to satisfy it.
- **Correction:** When the user rejects agent-introduced work, remove it and all residue that exists only because of it, including comments, tests, docs, naming, and delivery text.
- **Delivery:** Describe the accepted final state, not rejected detours or actions not taken. Mention them only when they leave material risk or unresolved impact.
