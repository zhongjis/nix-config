# Final-State Contract

- **Scope:** Treat the agreed task, including subsequent user changes, as the scope. Every changed line must be necessary to satisfy it.
- **Correction:** When the user rejects work introduced by the agent, remove it and any residue that exists only because of it, including comments, tests, docs, naming, and delivery text. Preserve user-owned and concurrent changes.
- **Delivery:** Describe the accepted final state, not rejected detours or actions not taken. Mention them only when they leave material risk or unresolved impact.
